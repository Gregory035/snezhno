# Снежно

Бесплатное приложение для macOS. Снег идёт поверх рабочего стола, собирается на окнах и Dock, а сугробы перемещаются вместе с окнами. В обычном режиме клики проходят сквозь снег.

## Установка

1. Скачай `Snezhno-macOS-universal.zip` из [Releases](https://github.com/Gregory035/snezhno/releases/latest).
2. Распакуй архив, перенеси «Снежно» в «Программы» и открой его. Управление находится под значком ❄︎ в строке меню.
3. Если macOS заблокирует первый запуск, открой **Системные настройки → Конфиденциальность и безопасность → Всё равно открыть** и подтверди запуск. У сборки локальная подпись, без нотариального заверения Apple. [Инструкция Apple](https://support.apple.com/102445)

Нужна macOS 13 Ventura или новее. Архив содержит универсальную сборку для Apple Silicon и Intel.

## Управление

- **Снегопад** — выбери интенсивность, ветер и частоту кадров. Отключи снег поверх окон, чтобы снежинки были видны на свободных участках рабочего стола.
- **Сугробы** — отдельно включай снег на окнах, Dock и внизу экрана. Настрой высоту и скорость накопления. Резкое движение окна стряхивает снег с кромки. Боковые миниатюры Stage Manager не собирают снег. Опция **Поднимать снег вместе с Dock** переносит сугроб с нижнего края на появляющийся Dock и возвращает его вниз при скрытии.
- **Варежка** — проведи курсором вдоль сугроба, чтобы смахнуть снег.
- **Снежки** — дай снегу накопиться. Зажми кнопку мыши возле сугроба и веди вдоль него, чтобы ком рос. Отпусти над краем окна, чтобы поставить ком. Сложи три кома от большего к меньшему, чтобы появился снеговик с глазами, морковкой, руками-веточками, красным шарфом и шапкой с бубончиком. Верни обычный курсор клавишей Esc после начала перетаскивания или через меню. Пункт **Поставить снеговика** сразу ставит готового снеговика на окно.
- **Очистить снег** — убирает сугробы и снежки. **Пауза** временно скрывает снег и останавливает анимацию.

В разделе **Управление** можно включить запуск при входе в macOS. Если снежинка в строке меню пропала, открой «Снежно» из «Программ», чтобы вернуться к настройкам.

Снег работает на подключённых мониторах. Каждый экран отрисовывается через Metal с независимым таймером, включая внешние мониторы с высокой частотой обновления. В режиме энергосбережения анимация становится легче. Пауза для полноэкранных приложений включена по умолчанию. Для сугробов используются координаты окон, разрешение на запись экрана не требуется.

## Сборка из исходников

Если инструменты разработчика Apple ещё не установлены, запусти `xcode-select --install` и дождись окончания установки.

```sh
git clone https://github.com/Gregory035/snezhno.git
cd snezhno
bash scripts/build.sh
open dist/Snezhno.app
```

Для универсальной сборки используй `bash scripts/build.sh --universal`. Приложение написано на Swift с AppKit, SwiftUI и SpriteKit. Сторонних зависимостей нет.

Ориентир для эффекта и управления — [Flake](https://tryflake.ru/).
